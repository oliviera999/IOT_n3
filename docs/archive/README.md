# Archive — Rapports ponctuels

Ce dossier contient les sorties d'audits, vérifications et diagnostics ponctuels (snapshots à une date donnée). Conservés pour référence historique ; pour la doc de référence à jour, voir le dossier parent `docs/`.

| Type | Description |
|------|-------------|
| check-pages-* | Rapports de vérification des pages serveur (scripts check-server-pages, etc.) |
| rapport_* | Rapports de vérification (galeries, graphiques, pages) |
| resume_* | Résumés de vérifications |
| diagnostic-* | Diagnostics serveur ponctuels |
| audit-serveur-complet-* | Audit complet à date |
| analyse_pages_meteo_* | Analyse pages météo |
| homepage_snapshot.html | Snapshot HTML de la homepage |
